# Webtech-Exp4
Aim :
To develop a website using HTML5 tags and apply styles to the website using advanced CSS3 properties such as rounder corners, border images, multiple backgrounds, gradients, shadows.

Description:
This experiment demonstrates the use of Advanced CSS3 properties to design an attractive webpage. It applies rounded corners (border-radius), border images, multiple backgrounds, gradients, text shadow, box shadow, and responsive design using media queries.


Procedure:

1.	Open Visual Studio Code and create a new HTML file named index.html.
2.	Create the basic HTML5 structure using the required tags.
3.	Add suitable headings, paragraphs, images, and other webpage content.
4.	Create a CSS file named style.css and link it to the HTML file.
5.	Apply border-radius to create rounded corners for elements.
6.	Use border images and multiple backgrounds to improve the webpage appearance.
7.	Apply linear and radial gradients to create attractive backgrounds.
8.	Use text-shadow to add shadows to text.
9.	Apply box-shadow to create shadow effects around elements.
10.	Use media queries to make the webpage responsive on different screen sizes.
11.	Save the files and open the webpage in a browser to verify the CSS effects.
